# Q03 — Sum the Even Numbers

Proposed quest; not instructor-approved. All three languages implement the same statement.

Print the sum of all even integers from 1 through n, including n when it is even. If there are no such integers, print 0.

One integer n from 0 through 100,000. Use a 64-bit integer in Java/C#; the sum can exceed a 32-bit signed integer.

Input: one integer n. Output: the sum as one integer.

Example input:
```text
6
```

Example output:
```text
12
```

Print only the answer and an optional final newline; no prompts. Python uses standard input/output; Java uses `Solution.main(String[] args)`; C# reference uses `Solution.Run()` for the existing wrapper. These are proposed learning tasks, not an approved curriculum catalog.
