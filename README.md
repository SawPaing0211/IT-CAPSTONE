# Forge.Dev

Forge.Dev is a programming-learning platform for Python, Java, and C#.

## Download the current application

The current application and Windows setup guide are on the **`master`** branch.

1. Open the [current branch](https://github.com/SawPaing0211/IT-CAPSTONE/tree/master).
2. Click **Code → Download ZIP**, then extract it.
3. Open the [setup guide](https://github.com/SawPaing0211/IT-CAPSTONE/blob/master/README.md) to run Forge.Dev locally.

If you use Git, clone the current branch directly.

```powershell
git clone --branch master https://github.com/SawPaing0211/IT-CAPSTONE.git
cd IT-CAPSTONE
```

For access to the hosted app, ask the group for the current link and your assigned account.
